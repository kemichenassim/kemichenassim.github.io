📩 Classification de SMS Spam
NLP Python BERT Scikit-learn TensorFlow

Système de classification automatique pour distinguer les SMS légitimes (*Ham*) des messages indésirables (*Spam*).

📚 Leçon clé : L'accuracy seule est trompeuse sur un dataset déséquilibré. Les métriques comme le Recall et l'AUC-ROC sont essentielles.

Résultats :

  • TF-IDF : très bon compromis performance/simplicité
  • BERT : meilleure performance sémantique
  • Autoencodeur : échec sur la classe minoritaire
